Ways to Contribute to Open Recipe Hub

You don't need to code to contribute to Open Recipe Hub! Here are several ways you can help make the project better for everyone. Every contribution counts! 🍴✨

📝 Recipe Translations

Help make recipes accessible to a global audience by translating them into languages like Hindi, Spanish, French, or others.

  • Translate recipes accurately, preserving culinary terms.
  • Submit translations in Markdown or JSON format via pull requests.

📸 Add Recipe Photos

Enhance recipes with high-quality visuals to make them more appealing.

  • Upload your own photos or use free stock images from Unsplash or Pexels.
  • Include short, descriptive alt text for accessibility (e.g., "A plate of creamy pasta with fresh basil").

🎨 UI/UX Design

Improve the app's look and feel with design suggestions.

  • Use tools like Figma or Canva to create mockups for layouts, color themes, or dark mode.
  • Share ideas for improving user experience, such as better navigation or button placement.

📖 Improve Documentation

Help make our documentation clearer and more user-friendly.

  • Fix typos, grammar, or formatting in files like README.md or CONTRIBUTING.md.
  • Write or improve setup guides, FAQs, or beginner-friendly tutorials.

🌟 Content Curation

Contribute to the recipe collection and organization.

  • Add new recipes in Markdown or JSON format following the project's template.
  • Categorize recipes (e.g., Vegan, Desserts, Quick Meals).
  • Curate "Top Recipes" lists or themed collections.

🌍 Community & Outreach

Spread the word and support the community.

  • Promote the project on social media, blogs, or other platforms.
  • Translate documentation into other languages.
  • Answer questions or provide help in Issues or Discussions.

🧪 Manual Testing

Ensure the app works smoothly by testing it.

  • Try out the app and report bugs or issues in the Issues section.
  • Suggest usability improvements (e.g., "The search bar could be more visible").

Thank you for contributing to Open Recipe Hub! Your efforts help build a vibrant, inclusive community. ❤️ If you have questions, check the Issues or Discussions sections, or reach out to the maintainers.
